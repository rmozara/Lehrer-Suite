# Lehrer-Suite

Die Lehrer-Suite ist eine Sammlung von Materialien, Vorlagen und Software zur Organisation und Unterstützung schulischer Arbeit.

Die Ordnerstruktur bildet verschiedene Bereiche des schulischen Arbeitsalltags ab und kann als Ausgangspunkt für eine eigene Arbeitsumgebung verwendet und angepasst werden.

## Software

Unter `Software/` befindet sich die Collector-Suite mit den Komponenten QR-Generator, SE-Collector (Selbstevaluation) und HB-Collector (Hefterbewertung) sowie einem vollständigen synthetischen Beispiel-Durchlauf.

Weitere Bereiche der Lehrer-Suite werden schrittweise ergänzt.
