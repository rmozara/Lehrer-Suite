# Prüfkonzept SE-Collector 1.0.0

Vor einer Veröffentlichung werden automatisiert geprüft:

- vollständige SE-Auswertung mit Bereichssummen, Gesamtwert und Notenschlüssel
- ODS-Struktur, Formeln, Datumsübernahme und wiederholte Aktualisierung
- Schülerzuordnung über unveränderte Schüler-IDs
- Direktmodus, Zwei-QR-Zugang und persönlicher Ersatzcode
- Sitzungsverwaltung, Wiederfreigabe und Live-Abgabestand
- A4-Auswertung mit unveränderter Feldzeile für Name, Klasse und Datum
- getrennte Arbeitsordner bei gemeinsamer Installation
- gemeinsamer Token mit QR-Generator und HB-Collector
- Linux- und Windows-Startskripte sowie Suite-Systemprüfung

Zusätzlich ist vor dem praktischen Einsatz auf dem vorgesehenen Gerät zu prüfen:

- Erreichbarkeit im Unterrichts-WLAN
- Kamera- und Bildauswahl auf den Schülergeräten
- PDF-Ausgabe mit der installierten LibreOffice-Version
- gleichzeitige Zugriffe einer vollständigen Lerngruppe
